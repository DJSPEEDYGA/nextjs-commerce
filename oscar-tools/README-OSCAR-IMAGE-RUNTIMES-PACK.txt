This pack adds local image generation runtimes into Oscar's one-folder system.

Files:
- OSCAR-ADD-IMAGE-RUNTIMES.sh
- README-OSCAR-IMAGE-RUNTIMES.txt (generated into Oscar root when installer runs)

Recommended use:
1) Copy or unzip this pack onto the same drive as Oscar.
2) Run:
   bash ./OSCAR-ADD-IMAGE-RUNTIMES.sh /path/to/OSCAR-THOR-ONE-FOLDER
3) Start:
   bash /path/to/OSCAR-THOR-ONE-FOLDER/START-OSCAR-IMAGE-RUNTIMES.sh
4) Test:
   bash /path/to/OSCAR-THOR-ONE-FOLDER/TEST-OSCAR-IMAGE-RUNTIMES.sh
