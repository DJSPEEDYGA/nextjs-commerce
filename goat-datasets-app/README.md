### What Is This?

The GOAT Datasets App gives you **instant access** to 41+ of the world's best AI/ML training datasets from HuggingFace Hub — **without any API keys, accounts, or logins**. Just download and run.

### Features

- 🔥 **41 Pre-loaded Top Datasets** — Instantly browse the most popular HuggingFace datasets
- 🔍 **Live HF Search** — Search 200,000+ datasets on HuggingFace Hub in real-time (no auth!)
- ⬇️ **Direct Downloads** — Download READMEs, individual files, or full datasets
- 📊 **Dataset Details** — View file listings, README previews, tags, stats
- 💾 **Local Management** — Track downloaded datasets, analyze contents, delete when done
- 📡 **Real-time Progress** — SSE-powered live download progress tracking
- 🖥️ **Desktop App** — Electron wrapper for Windows, macOS, and Linux
- 🔓 **Zero Auth** — No API keys, no tokens, no logins, no accounts needed

### Quick Start (Web Server)

```bash
cd goat-datasets-app
npm install
npm start
# Open http://localhost:4002
```

### Quick Start (Desktop App)

```bash
cd goat-datasets-app
npm install
npm run electron
```

### Build Desktop Installer

```bash
npm run build:win    # Windows .exe
npm run build:mac    # macOS .dmg  
npm run build:linux  # Linux .AppImage
npm run build:all    # All platforms
```
