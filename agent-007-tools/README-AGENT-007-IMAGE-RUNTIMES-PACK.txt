This pack adds local image generation runtimes into Agent-007's one-folder system.

Files:
- AGENT-007-ADD-IMAGE-RUNTIMES.sh
- README-AGENT-007-IMAGE-RUNTIMES.txt (generated into Agent-007 root when installer runs)

Recommended use:
1) Copy or unzip this pack onto the same drive as Agent-007.
2) Run:
   bash ./AGENT-007-ADD-IMAGE-RUNTIMES.sh /path/to/AGENT-007-THOR-ONE-FOLDER
3) Start:
   bash /path/to/AGENT-007-THOR-ONE-FOLDER/START-AGENT-007-IMAGE-RUNTIMES.sh
4) Test:
   bash /path/to/AGENT-007-THOR-ONE-FOLDER/TEST-AGENT-007-IMAGE-RUNTIMES.sh
